---
name: موافقة المزامنة وفصل الحسابات
description: حدود الخصوصية المختارة عند إدخال الحسابات إلى تطبيق كان محليًا
---

تسجيل الدخول ليس موافقة على رفع خطة المتصفح القديمة. تبقى خطة «دون حساب» مستقلة، ويتطلب نسخها إلى الحساب تأكيدًا بأنها تخص الطالب، ثم موافقة منفصلة قبل الرفع.
نقل خطط المراجعة بين الأجهزة عبر ملف نسخة احتياطية محلي واختياري؛ لا تدخل الخطط أو روابطها في دمج السحابة أو الحسابات.

**Why:** طلب المستخدم الحفاظ على البيانات الحالية وعزل بيانات كل طالب، مع موافقة واضحة قبل رفع البيانات المحلية؛ وقد طلب نقل خطط المراجعة دون إضافة مزامنة أو حسابات.

**How to apply:** لا تحوّل بيانات الضيف تلقائيًا إلى ملكية أول حساب يسجّل الدخول. اختيرت المزامنة اليدوية لتبقى لحظة الرفع واضحة؛ وأي نقل لخطط المراجعة يتطلب اختيارًا صريحًا داخل النسخة الاحتياطية، ولا يجوز أن يتجاوز مراجعة التعارضات أو تأكيد تحديث التذكيرات الخلفية.
